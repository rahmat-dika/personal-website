Innovation Management System

Innovation Management System

Overview

Innovation Management System is a web-based platform built from the ground up to collect and manage innovation ideas submitted by employees. Unlike other projects that involved enhancing existing systems, this one was a greenfield build — and it had to work seamlessly across all four companies within the UTPE Group from day one.

The Challenge

Supporting four companies simultaneously introduced a challenge beyond system design: user data for three of the four subsidiary companies was incomplete or unmaintained, unlike the parent company. Without accurate user data, the platform risked access issues and unreliable tracking of who submitted what — right at launch.

  • Challenges arise when there are discrepancies in data among companies within the UTPE Group.
  • Data synchronization for the developed application.

Case Information

  • Company : PT United Tractors Pandu Engineering
  • Date : Feb 2024 – Jul 2024
  • Progress : Go Live
  • User : All Employee
  • Location : UTPE Group – 4 subsidiary companies

The app's results once the data has been successfully synced


The Approach

I queried the database directly via SQL to identify exactly which user records were missing or incomplete across the three subsidiaries. Rather than treating this as a purely technical fix, I coordinated directly with each subsidiary's HRD team, sharing the specific data gaps I'd found and requesting they complete the missing records before rollout. Alongside this, I owned the project end-to-end — from requirement analysis and system design through development and UAT.

The Result

The platform launched successfully across all four companies with clean, reliable user data in place. Beyond the technical build, the project demonstrated the value of pairing data analysis with direct cross-functional coordination — resolving a data quality issue that a purely technical fix couldn't have addressed alone.
